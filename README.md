# Netflix-clone

A high-fidelity recreation of the Netflix Landing Page built with a focus on responsive design and modern front-end styling. This project demonstrates the use of Bootstrap's grid system and custom CSS to match a real-world brand's UI/UX.

## 🚀 Features
Responsive Design: Fully functional across Desktop, Tablet, and Mobile devices using Bootstrap 5.
Hero Section: Features a high-resolution background with a darkened linear-gradient overlay for text readability.
Custom Styling: Accurate "Netflix Red" branding and typography.
Interactive Components: Hover states for buttons, styled input fields, and a clean navigation bar.
## 🛠️ Tech Stack
HTML5: For semantic web structure.
CSS3: Custom styling and layout refinements.
Bootstrap 5: Utilized for the responsive grid, utility classes, and layout components.
